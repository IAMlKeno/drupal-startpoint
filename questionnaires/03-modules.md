# Contributed module questionnaire (Module Agent)

## Functionality
1. List required features (forms, search, SEO, e-commerce, events, newsletter, SSO, maps, etc.)
2. Nice-to-have features
3. Third-party integrations (CRM, analytics, payments, email, APIs)

## Constraints
4. Modules you already use, love, or refuse to use
5. Maintenance tolerance: only well-maintained, security-advisory-covered modules, or are niche modules acceptable?
6. Hosting limits (memory, Redis/Solr/Elasticsearch availability, no shell access)
7. Performance and security requirements
8. Licensing or budget constraints (e.g. paid services)

## Existing sites only
9. Provide `composer.json`/`composer.lock` or module inventory
10. Modules known to be problematic, abandoned, or blocking Drupal 11

## Review preferences
11. How many alternatives per requirement (default 2-3)?
12. Prefer core even if contrib is more convenient? (default: yes)
