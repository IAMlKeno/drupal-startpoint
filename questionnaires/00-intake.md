# Intake questionnaire (Orchestrator)

Answers are saved to `docs/project-brief.md`. Ask in small groups. Skip what does not apply.

## Project
1. Project name and machine name (used for DDEV: `<name>.ddev.site`)
2. New site or existing site?
3. Site purpose and goals (what should it achieve? for whom?)
4. Primary audiences and rough traffic expectations
5. Timeline and any hard deadlines

## Technical
6. Drupal 11 minor version target (default: latest stable 11.x); PHP version (default 8.3+)
7. Hosting / deploy target (Pantheon, Platform.sh, Acquia, VPS, undecided)
8. Environments and config approach (single env, or dev/stage/prod with Config Split?)
9. Git host and branching preference
10. Existing constraints (must-use modules, forbidden modules, performance budgets, security/compliance)

## Editorial and access
11. Who creates, edits, and publishes content? Approval workflow needed?
12. Multilingual? Which languages?
13. Accessibility target (WCAG 2.2 AA default)
14. SEO and analytics requirements

## Existing site only
15. Current Drupal version and where the codebase lives
16. Sanitized DB snapshot provided? (never production access)
17. What must not change? What is wrong today?
18. Content migration needs (source, volume, mapping)

## Approvals
19. Who signs off on mock-ups, module list, and content types?
20. Anything else we should know?
